# Style Guide

Colors

- Primary (violet): #7c3aed
- Accent (cyan): #06b6d4
- Background gradient: #071033 → #0f172a

Spacing

- Base radius: 14px
- Card padding: 1.5rem

Utility classes

- `app-container`: centers content, max-width 1200px
- `card`: glassy card surface
- `interactive-card`: hover lift + shadow
- `btn`, `btn-primary`, `btn-ghost`: primary button styles

Accessibility

- `:focus-visible` outlines for keyboard navigation

Usage

- Wrap page content in `.app-container` for consistent layout
- Use `.card` for isolated panel UI; prefer `.interactive-card` for clickable items
